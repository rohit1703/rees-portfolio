# Holding page for rees-portfolio

One static page ("Ree's Portfolio") with self-hosted fonts. Every path shows this page.

Deploy (needs Node 20+):

```bash
npm run deploy:link   # once: connects this folder to the rees-portfolio project
npm run deploy        # publishes to production
```

To edit the text, change the `<h1>`, `<p>` and `<footer>` in `index.html`.
